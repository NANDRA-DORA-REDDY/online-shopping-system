ONLINE SHOPPING SYSTEM — NEXT STEPS

1. Upload this project to GitHub.
2. Create a MySQL database/service in Railway.
3. Run database/schema.sql once on the Railway MySQL database.
4. Deploy the GitHub repository as a Railway service.
5. Railway will use the Procfile and the MYSQL* variables.
6. Open the generated Railway URL.
7. Register a customer and test Products -> Cart -> Checkout -> Orders.

IMPORTANT:
- Do not upload .env files or database passwords to GitHub.
- The sample database data comes from the college project documentation.
